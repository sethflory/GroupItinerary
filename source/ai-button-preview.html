code CSS Implementation

Copy these CSS variables to implement the emerald theme.

:root {
  /* Emerald AI Theme */
  --ai-emerald-dark: #134e5e;
  --ai-emerald-light: #71b280;
  --ai-emerald-mid: #2d7a6d;
  --ai-emerald-glow: rgba(113, 178, 128, 0.4);

  /* Gradient */
  --ai-gradient: linear-gradient(135deg, #134e5e 0%, #71b280 100%);

  /* Shadow */
  --ai-shadow: 0 4px 20px rgba(19, 78, 94, 0.35);
  --ai-shadow-hover: 0 6px 28px rgba(19, 78, 94, 0.45);
}
